# Feedback

All rights reserved. The source is public to read. This is a read-only public snapshot; issues are welcome, and pull requests are not merged. No license to reuse or redistribute the code is granted.

Please open an issue for a bug, unclear documentation or a question about the design. Include the relevant file or command, expected behavior, observed behavior and a minimal synthetic example when possible. Do not include credentials, private data or production logs containing personal information.

Start with the [glossary](docs/glossary.md), [architecture](docs/architecture.md) and [developer guide](docs/DEVELOPING.md) to understand the source and its verification commands.
